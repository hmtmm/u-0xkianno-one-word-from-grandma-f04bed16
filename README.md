A program that writes one word — the single word a grandma would text about AI — to /output/entry.txt. The word is "robit": grandma trying to type "robot" and landing one letter off, warm, a little baffled, and funny in one word with no caption needed.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
